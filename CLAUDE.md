# Contexto obligatorio para Claude Code

El Master Operations Map de Kapta está versionado en
`docs/mom/master-pedidos-v1.md`. Léelo antes de trabajar en el Master de
Pedidos o en cualquier flujo logístico, financiero o de cierre.

Sigue también `AGENTS.md`. Cuando una implementación cambie una regla del
negocio, actualiza la especificación MOM y sus pruebas en el mismo commit. No
uses una captura de Miro como única especificación ni inventes estados que no
estén documentados.
